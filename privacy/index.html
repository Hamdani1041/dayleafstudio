Dayleaf Studio · Pin Publisher

Privacy Policy

Effective 4 September 2026 Last updated 4 September 2026 Applies to Dayleaf Studio Pin Publisher

In short

This application is a private tool used by one person — the owner of the Dayleaf Studio shop — to publish Pins to their own Pinterest account.

It has no users other than its owner, collects nothing from anyone else, and shares no data with third parties.

What this application is

Dayleaf Studio Pin Publisher is a script run on the shop owner's own computer. It takes product images prepared offline and posts them as Pins to boards belonging to the Dayleaf Studio Pinterest business account.

It is not a website, a hosted service, or a product offered to anyone else. There is no sign-up, and no one but the owner can operate it.

What it accesses on Pinterest

The application acts only on the single Pinterest account that authorises it, using that account's own permissions.

Pinterest data touched, and why
DataWhy it is used
BoardsTo list the owner's own boards, so a Pin can be placed on the right one.
PinsTo create new Pins, and to confirm a Pin was created.
Account nameTo confirm the correct account is connected before publishing.

It does not read, collect, or process the Pins, boards, profiles, or activity of any other Pinterest user.

What is stored, and where

One thing is stored: the OAuth access token Pinterest issues when the owner grants permission. It is kept in a local configuration file on the owner's computer and is used only to authenticate that account's own API requests.

There is no server, no database, and no cloud storage. No Pinterest content is copied or retained after a Pin is published.

What it never does

  • It does not sell, rent, or trade any data.
  • It does not share data with third parties, advertisers, or analytics providers.
  • It does not use Pinterest data to train machine-learning or AI models.
  • It does not access the data of Pinterest users other than the account that authorises it.
  • It does not track visitors, because it has no visitors — it is a local script, not a site.

Withdrawing access

Because the only account involved is the owner's own, access can be withdrawn at any time from Pinterest's Settings → Apps, which revokes the token immediately. Deleting the local configuration file removes the stored token from the computer.

Children

The application is a business tool for one adult shop owner. It is not directed at children and is not made available to them.

Changes to this policy

If what the application does changes, this page is updated and the "last updated" date above changes with it.

Contact

Questions about this policy can be sent through the Message Seller link on the Dayleaf Studio shop page on Etsy, which reaches the same person who operates the application.
